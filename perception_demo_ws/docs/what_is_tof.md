# ToF 相机调研报告

## 1. 概述

ToF 相机（Time-of-Flight Camera）是主动式深度相机：用近红外光照射场景，在面阵传感器上逐像素测量光的飞行时间或相位差，输出深度图、红外图，并可生成点云。部分机型同步输出 RGB，形成 RGB-D。

面向小型移动机器人（扫地机、商用清洁、配送、四足等）时，业界常见一类**紧凑型机器人深度相机**：体积小、功耗低、广视场，常把**近距避障**与**中远距建图/SLAM**做在同一模组里。光鉴科技 Deptrum **Nebula 系列**（公开型号含 Nebula 220 / 240 / 400 / 410 等）是该类产品的典型代表；同类还有英飞凌 REAL3 路线的 **hToF 混合 ToF 模组**、迈尔微视 **MRDVS S 系列**、海康机器人紧凑 ToF、以及主动双目路线的奥比 **Gemini** 等。

本报告以该形态 ToF / 混合 ToF 深度相机为主线，说明工作原理、常用参数、小型机器人应用，并对比主要竞品。

## 2. ToF 相机如何工作

### 2.1 基本测距

光往返时间 t 与距离 d 的关系：


d = \frac{c \cdot t}{2}


其中 c 为光速。面阵 ToF 相机对视场内每个像素独立求距离，一次曝光得到整幅深度图。

### 2.2 两种基础实现


| 类型            | 方法                                         | 特点                              |
| ------------- | ------------------------------------------ | ------------------------------- |
| **iToF（间接式）** | 发射调制连续光，测相位差 \varphi，d = c\varphi/(4\pi f) | 易做较高分辨率深度图；近中距主流；多径干扰（MPI）需算法抑制 |
| **dToF（直接式）** | 短脉冲 + 计时（常配合 SPAD/直方图）                     | 更擅中远距与强光；分辨率往往更稀疏               |


消费与商用机器人模组中，英飞凌 REAL3 等多为可配置 iToF 成像器；工业移动机器人相机中也有 dToF RGB-D（如 MRDVS S 系列）。

### 2.3 Nebula 类：结构光 + ToF 的混合形态（sToF / mToF）

Nebula 系列的关键点不是“纯 iToF 开发套件”，而是**同一套光学硬件上融合结构光与 ToF**：

- **近距（避障）**：用结构光/调制光场做高精度重建（厂商称 **sToF**），抑制墙角等多径伪影，覆盖约数厘米～1 m 级地面障碍。
- **中远距（SLAM/建图）**：用调制 ToF（厂商称 **mToF**）输出更大范围深度，白墙反射率较高时可达数米至约 8 m。
- **光学核心**：自研 WFP（波前/纳米光子）芯片调制投射光场，配合双重建算法，使单一模组替代“顶部 LDS + 前方避障”的传统双传感器方案。

英飞凌 / pmd / OMS 的 **hToF（Hybrid ToF）** 思路相近：单颗 REAL3 成像器 + **双照明**（泛光高分辨率近场 + 点阵/远距照明），把高分辨率避障与远距稀疏深度（用于建图）合在一个约 31\times16\times8\mathrm{mm} 量级的模组里。石头科技等扫地机已量产采用。

### 2.4 从原始测量到可用深度

典型链路：调制照明 → 面阵采样（相位/时间）→ 多频或混合解算 → 标定与温漂补偿 → 飞点/置信度过滤 →（可选）RGB 对齐与点云。机器人侧再跑地面分割、障碍物检测、3D SLAM 等。

### 2.5 主要误差与伪影


| 现象        | 说明                                            |
| --------- | --------------------------------------------- |
| 多径干扰 MPI  | 墙角、镜面多重反射导致距离偏大；纯 iToF 更明显，混合 sToF/hToF 以此为卖点 |
| 飞点        | 深度跳变边缘前景/背景混叠                                 |
| 强环境光      | 阳光淹没回光；机器人模组多强调 80k～100k lux 级抗光              |
| 低反射 / 高反光 | 黑物、玻璃易空洞或跳变                                   |
| 运动模糊      | 曝光窗口内机体/目标快速运动                                |

**对标结论（简要）**：

- 与 Nebula **最同构**的是 **hToF / REAL3 混合模组**：都强调「一颗相机做避障+建图、去掉机械 LDS、机身更薄」。
- **MRDVS S10** 同属机器人前视 RGB-D，但走 **dToF + 工业接口**，更偏 AMR/室外，分辨率更稀、量程与防护更强。
- **Gemini** 是主动双目竞品，室外与远距往往更强，但原理与多径特性不同，算力与基线约束不同。
- **Femto / Azure Kinect 类** 深度模式丰富、分辨率高，更适合开发与人机交互，不作为 Nebula 类超薄 OEM 模组的直接替代。

## 5. 在小型机器人上的应用实例

### 5.1 扫地机器人：去 LDS、降机身、避障+建图一体

- **Nebula 220/240**：单一模组完成近距 3D 避障与远距深度用于 SLAM，减少顶部旋转 LDS 的高度、噪声与机械磨损；利于机身降至约 8 cm 级钻床底。
- **hToF（REAL3）**：石头 Qrevo Slim 等量产机采用，混合照明同时服务路径规划与小物体绕行。
- 典型安装：机头略上仰，兼顾地面线缆、鞋、宠物粪便等矮障碍与前方墙面/家具。

### 5.2 商用清洁 / 配送 / 巡检机器人

- **Nebula 400**：3 cm～8 m、广 FOV、可选以太网与 IP67，用于楼宇清洁、送餐配送；算法侧可叠加地面分割、细线/污物识别、室内 3D SLAM。
- **MRDVS S10**：仓库 AMR、室外低速无人车，强调 100 klux 与网口长距离布线。

### 5.3 四足、陪伴、轮椅等低矮平台

- **Nebula 410** 等超小 MIPI：在体积与成本敏感平台上提供近盲区小、视场大的前视深度；可外挂 USB 转接做原型。

### 5.4 与其他传感器的分工


| 传感器          | 角色       | 与 Nebula 类关系       |
| ------------ | -------- | ------------------ |
| 机械 LDS       | 传统 2D 建图 | 混合 ToF 模组的主要替代对象之一 |
| 线激光避障        | 近场截面     | 可被稠密 3D 深度取代或降配    |
| 超声波 / 单点 ToF | 悬崖、保险杠   | 仍常保留作冗余            |
| 2D LiDAR（工业） | AMR 远程导航 | ToF 相机补高度维与近场稠密障碍  |
| RGB 单目       | 语义       | 与深度融合做障碍分类         |

## 6. 选型要点

1. **先定任务**：仅近场避障 vs 必须同时支撑 SLAM；决定是否需要 sToF/mToF 或 hToF 双模式。
2. **机身约束**：MIPI 超薄模组适合扫地机；网口/IP67 适合商用与户外。
3. **光照与材质**：按目标场景实测黑物、玻璃、逆光；看抗 lux 指标与置信度输出。
4. **帧率与算力**：该类产品常见约 10 fps，需确认导航控制环是否够用；问清深度算在模组侧还是主机侧。
5. **生态**：Windows/Linux SDK、ROS/ROS2、是否提供地面分割与同步接口。

## 8. 结论

面向小型机器人的 ToF 相机，核心价值是**主动、稠密、算力友好的三维前视感知**。以 **Deptrum Nebula 系列**为代表的形态，通过 **结构光与 ToF 混合（sToF/mToF）**，在厘米级近场到数米级远场之间用单模组覆盖避障与建图，并与 **英飞凌 hToF、工业 dToF RGB-D、主动双目** 等方案竞争。选型应紧扣工作距离与 FOV、近/远模式精度、抗光、模组尺寸/接口与主机算力，并结合黑物、玻璃、强光等场景实测。
