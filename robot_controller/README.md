# PetBot 终端驾驶控制

在 macOS 的“终端.app”或 iTerm2 中运行：

```bash
conda activate robot_env
cd ~/Developer/ROS_lesson/robot_controller
python main.py
```

程序加载 `../robot_description/mjcf/scene.xml`，初始隐藏 MuJoCo 左右面板。
macOS 需要 `mjpython` 承载图形主线程；入口会自动切换到当前 Python 环境的
`mjpython`，不需要手动更换启动命令。

## 键盘与焦点

- 上 / 下：前进 / 后退。
- 左 / 右：左转 / 右转，可与前后方向组合。
- 松开方向键：平滑减速；相反方向同时按住时，该方向输入抵消。
- 空格：减速停车。
- `c`：保留模式切换入口，目前只有普通模式，不改变控制状态。
- `q` 或 `Ctrl+C`：退出，并恢复终端输入设置。

点击启动程序的终端输入区域后控制机器人。点击 MuJoCo、其他应用或其他终端
输入区域后停止接收驾驶输入，并减速停车；头、双耳和左右车架继续保持零位。
返回原终端后可以继续操作。若启动时终端不在前台，首次在原终端按键时绑定焦点。

使用 macOS 物理按键状态判断按住和松开，不依赖终端自动重复速度，支持多键组合。
只查询上述控制键和快捷键修饰键，不保存键盘记录。
目前支持终端.app 和 iTerm2，不支持 IDE 集成终端或 SSH。

## 首次运行权限

精确按键检测需要“输入监控”，区分终端窗口/输入区域需要“辅助功能”。缺少权限时
程序会触发系统提示并退出，不会默默降级为按键重复控制。

进入“系统设置 → 隐私与安全性”，在上述两项中允许系统提示的终端或
`MuJoCo (mjpython)`。授权后退出并重新打开终端，再执行启动命令。
若系统要求手动选择应用，当前环境的承载程序是：

```text
~/miniforge3/envs/robot_env/lib/python3.12/site-packages/mujoco/MuJoCo_(mjpython).app
```

## 控制参数

默认最高目标线速度为 `0.35 m/s`，最高目标偏航角速度为 `1.5 rad/s`。
线加速度为 `0.35 m/s²`，减速度为 `0.65 m/s²`；转向加速度为
`2.5 rad/s²`，减速度为 `4.0 rad/s²`。反向操作先减速至零再反向加速。

```bash
python main.py --max-speed 0.25 --max-yaw-rate 1.0
```

其余参数在 `control.py` 的 `DriveConfig` 中调整。后轮半径 `0.030 m`、
后轮中心距 `0.100 m` 来自当前模型零位几何。差速轮速按模型驱动器范围限幅。
这些是目标速度上限，不是对实际机身速度的刚性约束。

头、双耳和左右车架采用独立 PID 力矩闭环（角度目标为零、速度反馈为微分项），
含力矩限幅和积分抗饱和。前轮保持被动，不添加驱动器。

**前轮低摩擦：** 控制程序在运行时将两个前轮与地面的滑动摩擦系数从有效值
`1.5` 降至 `0.05`（原来的 1/30），同时降低前后和侧向滑动阻力。配置位于
`control.py` 的 `FRONT_WHEEL_FRICTION`。前轮使用较高接触优先级，避免被地面的
较大摩擦系数覆盖。后轮与地面的摩擦仍为 `1.5`，质量、惯量、驱动力上限及几何不变。
前轮因此更容易滑动；实际线速度和偏航速度仍会受轮胎打滑与接触状态影响。

控制程序仅在内存中将数值积分器切换为 `implicitfast`，减少高增益轮速伺服在
原步长下的数值抖动。原始 MJCF、STL 和场景文件均不修改。

## 环境与检查

当前 `robot_env` 已安装依赖。重建环境时运行：

```bash
python -m pip install -r requirements.txt
```

在项目根目录运行自动测试：

```bash
python -m unittest discover -s robot_controller -v
```

测试包括加减速、反向刹车、焦点丢失、物理松键判定、零位恢复和力矩抗饱和。
焦点测试使用模拟系统接口；真实终端的权限和按键体验需授权后人工验证。
